# Hades II × Slay the Spire 2 Crosslink

A cross-game integration bridging **Hades II** and **Slay the Spire 2** for one-click installation via Melty.

Ingests authentic cards, relics, and class mechanics from your local Steam install of *Slay the Spire 2* directly into the *Hades II* combat loop.

---

## Prerequisites
* **Hades II** (Steam, Epic Games Store, or Standalone)
* **Slay the Spire 2** (Installed via Steam)

## Installation via Melty
1. Add this repository URL to Melty:
   `https://github.com/firey-frost/hades2-sts2-crosslink`
2. Select **Hades II** as the **Primary** game target.
3. Ensure **Slay the Spire 2** is installed so cards and relics can be ingested.
4. Launch the game directly from Melty.
